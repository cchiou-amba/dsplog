# Ambarella DSP Logger (DSPLOG) Kernel Driver

This repository packages the out-of-tree Ambarella DSP Logger
(`dsplog.ko`) kernel driver and logging interface headers for Ambarella
CV3 / N1-655 SoC platforms on EVE-OS.

---

## What the Kernel Module Does

The `dsplog.ko` module captures real-time diagnostic logs, execution
traces, and debug dumps generated by the on-chip DSP coprocessor:

- **DSP Ring Buffer Capture**: Reads execution logs directly from the
  DSP firmware circular trace buffer in reserved memory without
  disrupting real-time video processing.
- **High-Precision Timestamps**: Correlates DSP internal hardware timer
  ticks with Linux system monotonic time for accurate timeline
  debugging.
- **Crash Dump & Memory Snapshot**: Captures post-mortem DSP state
  dumps, register snapshots, and memory state when a DSP hang, watchdog
  timeout, or VisORC fault is detected.
- **Lossless Extraction Interface**: Exposes `/dev/dsplog` for userspace
  logging utilities, providing configurable ring buffer sizes, binary
  parsing, and text streaming.
- **Inter-Driver Communication**: Integrates with the `ambvideo` (`iav`
  and `dsp`) subsystem to receive runtime logging hooks and state
  notifications.

---

## Directory Layout

- `dsplog_drv.c`: Character device node implementation and file ops
- `dsplog_timer.c`: Hardware timer synchronization and polling logic
- `dsplog_priv.h`: Internal driver structures and buffer definitions
- `include/`: Interface headers required for DSP log parsing:
  - `dsplog_api.h`, `dsplog_drv.h`: Userspace and kernel log APIs
  - `dsp_api.h`, `dsp_format.h`: DSP command and format definitions
  - `iav_event_notifier.h`: Asynchronous event notification structures

## Building the Kernel Module

To compile `dsplog.ko` out-of-tree against the prepared EVE kernel
headers:

```bash
make KDIR=/path/to/linux-headers \
     ARCH=arm64 \
     CROSS_COMPILE=aarch64-linux-gnu-
```

The Makefile automatically resolves inter-module symbol dependencies
against `eve/ambvideo` when available.

The resulting kernel module will be generated at:
`dsplog.ko`

To clean build artifacts:

```bash
make clean
```

---

## Deployment to EVE-OS

1. Copy the compiled module to the target node:

```bash
scp dsplog.ko <node>:/persist/modules/
```

2. Load the driver on the target node (requires `ambvideo` modules to be
   loaded first):

```bash
insmod /persist/modules/dsplog.ko
```
